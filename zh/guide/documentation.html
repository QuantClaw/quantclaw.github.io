关键路径快速参考 ​

文件路径 ​

~/.quantclaw/
├── quantclaw.json              # 配置文件
├── skills/                     # 全局技能目录
└── agents/main/
    ├── workspace/
    │   ├── SOUL.md             # 助手身份
    │   ├── MEMORY.md           # 长期记忆
    │   ├── SKILL.md            # 技能声明
    │   ├── IDENTITY.md         # 能力自述
    │   ├── HEARTBEAT.md        # Cron 日志
    │   ├── USER.md             # 用户偏好
    │   ├── AGENTS.md           # Agent 列表
    │   └── TOOLS.md            # 工具指引
    └── sessions/
        ├── sessions.json       # 会话索引
        └── <session-id>.jsonl  # 单会话记录

服务端口

常用命令速查 ​

bash
quantclaw onboard --quick       # 初始化
quantclaw gateway run           # 前台启动网关
quantclaw agent "你好！"        # 发送消息
quantclaw eval "2+2"           # 一次性查询
quantclaw sessions list        # 查看会话
quantclaw memory search "..."  # 搜索记忆
quantclaw health               # 健康检查
quantclaw config get           # 查看配置
quantclaw doctor               # 诊断
quantclaw dashboard            # 打开 Web UI
